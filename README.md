# 麦日常（Mai_mylife）

`Mai_mylife` 让同一个麦麦实际阅读新闻、阅读小说、保存笔记和日记，并维护面向不同 QQ 用户的独立关系；同时支持群聊观察与转述。

当前版本 **1.2.0** · 插件 ID：`fraternity-z.mai-mylife` · [下载 Release](https://github.com/fraternity-z/maibot-mylife/releases/latest) · [更新日志](CHANGELOG.md) · [问题反馈](https://github.com/fraternity-z/maibot-mylife/issues)

日常使用固定任务时段，执行成功后才记录活动，不再用模型编造吃饭、出行、场景或梦境。Planner 可自主判断是否主动聊天，继续遵守用户额度、判断间隔、工作时段与免打扰。

## 打包与安装

### 运行要求

- MaiBot：`1.3.16～1.3.99`，需支持插件自定义 WebUI 页面。
- 插件 SDK：`2.7.0～2.91.99`，沿用 MaiBot 提供的 SDK。
- Python：`3.11` 或更新版本；宿主需已配置可用的 Planner、Replyer 和插件所用模型任务。
- Python 依赖：`chinese-calendar>=1.0,<2`、`lunar-python>=1.4,<2`，已在 Manifest 声明。缺少时仅降级节假日、农历与节气信息。

### 安装与更新

从 [Releases](https://github.com/fraternity-z/maibot-mylife/releases) 下载 `mai-mylife-1.2.0.zip`。首次安装：进入 MaiBot WebUI 的“插件扩展”→“更多操作”→“从 ZIP 安装插件”，选择 ZIP；按界面提示重启或重载，然后启用“麦日常”并完成下方配置。当前宿主 ZIP 安装器不会覆盖已安装的相同插件 ID。

也可手动安装：将 ZIP 内容直接解压到 `MaiBot/plugins/fraternity-z_mai-mylife/`，确保该目录直接包含 `_manifest.json` 和 `plugin.py`，不要再套一层目录。

更新已有安装时，先停用插件并备份原插件目录和 `MaiBot/data/plugins/fraternity-z.mai-mylife/`，再把 ZIP 内容覆盖到**原安装目录**，保留该实例的 `config.toml`、`config_back/` 和 `data/`；不要另建同 ID 的第二份插件。启用后用 `/麦麦状态`、`/麦麦休息测试` 检查加载、校时与工作时间，打开插件三个页面确认界面正常。

依赖由宿主根据 Manifest 安装。手动部署时，在运行 MaiBot 的同一个 Python 环境中执行 `python -m pip install -r requirements.txt`；Docker 部署需在容器运行环境中安装。官方安装说明：[安装插件](https://docs.maibot.chat/manual/plugins/)与[管理插件](https://docs.maibot.chat/manual/plugins/management)。

### 从源码打包

在本项目源码目录执行（无额外打包依赖）：

```powershell
python tools/build_plugin.py
```

生成 `dist/mai-mylife-1.2.0.zip`，文件名随 `_manifest.json` 的版本号变化。脚本读取当前工作树，包含尚未提交的运行代码，排除真实 `config.toml`、数据库、日志、个人日程模板、Git 和代码索引缓存。打包前会检查入口、页面、图标、Python 语法和版本一致性；不要直接压缩整个开发目录。

## 快速配置

大部分设置直接在 MaiBot WebUI 的插件配置页完成，不建议手写完整 TOML。

1. 在“私聊用户”中填写真实 QQ 号，并启用该用户。
2. 最多设置一个 `owner`，其他用户使用 `friend`。
3. 需要主动聊天时，开启该用户的“允许主动”，填写每日主动上限；需要不设上限时开启“每日主动不限次数”（`daily_proactive_unlimited = true`）。用户主动开关默认关闭。
4. 在“环境与天气”中填写城市和时区。中国大陆用 `Asia/Shanghai`，不需要修改服务器时区。
5. 保存配置并重载插件，使用 `/麦麦状态` 检查任务和模型状态。

管理员 QQ 可以直接在私聊使用菜单、状态、配置和诊断指令，不需要再重复创建私聊用户档案。关系温度和重要日期属于个人档案功能，只有把当前 QQ 加入“私聊用户”并启用档案后才可使用。

输入 `/麦麦` 或 `/麦麦帮助` 会返回纯文本指令菜单。以 `/麦麦` 或 `/mai` 开头但未识别的指令会显示同一菜单。

### WebUI 页面

| 页面 | 内容 |
| --- | --- |
| 麦麦此刻 | 当前任务、实际执行记录、今日任务时段与 Token 统计 |
| 记忆与牵挂 | 关系、重要日期、日记、阅读笔记和联网见闻 |
| 系统与配置 | 运行诊断、主动巡检、群白名单和配置；可编辑的标量配置经确认后保存并热生效 |

### 时间与回复设置

插件启动时自动联网校时，优先 NTP 多时间源，UDP 不可用时回退 HTTPS 时间；之后每小时后台刷新。成功后用单调时钟推进，服务器本地时区或系统时钟跳变不会改变插件时间。断网时延续上次校准；首次校准也失败时回退系统 UTC 并记录告警，每 5 分钟重试。Planner、Replyer、日程和工作时段统一使用配置时区的时间。联网校时独立于新闻/搜索总开关。

- **私聊必回**：没有概率配置，默认全天放行；可在“私聊回复”设置工作时间。
- **群聊按概率回复**：默认每条消息 `0.18`（18%），在“群聊设置”修改概率与工作时间；`0` 为不触发，`1` 为每条触发。
- `work_start` 包含开始时刻，`work_end` 不包含结束时刻；支持跨午夜，起止相同表示全天。所有时段按 `environment.timezone` 计算。
- 关键词、@、图片和日程活动均不改变这套规则。普通消息在工作时间外静默，私聊主动巡检也遵守私聊工作时间；命令仍按原有权限执行。
- 群聊概率命中后直接请求宿主调度，跳过宿主动态触发阈值。管理员暂停、模型故障、发送失败仍可能导致没有实际回复；连发合并和发送防重仍由原流程处理。
- 未通过工作时间或群聊概率的消息不会进入宿主聊天上下文，也不再积压供以后补答。

例如：私聊全天必回，群聊每天 08:00–23:00 按 20% 概率回复：

```toml
[environment]
timezone = "Asia/Shanghai"

[rest_gate] # 保留旧节名；现在只控制私聊工作时间
enabled = true
work_start = "00:00"
work_end = "00:00"

[group]
gate_enabled = true
reply_probability = 0.2
work_start = "08:00"
work_end = "23:00"
```

旧配置自动迁移：启用的固定夜间休息窗转为其外侧工作时段；旧日程模式和已关闭的旧门控转为全天。旧关键词、午休门控、判醒模型和私聊醒来概率不再使用。保存配置后检查工作时间是否符合预期。使用 `/麦麦休息测试` 查看当前完整时间、校时来源和回复设置。

### 手动编辑规范

必须手动修改 `config.toml` 时：字符串和 QQ 号使用英文双引号，布尔值使用小写 `true/false`，时间使用 `HH:MM`，不要填写 `null` 或 `None`。`plugin.config_version` 由插件维护，不要修改。

## 联网搜索

内置新闻源直接读取公开 RSS，无需搜索 API Key。网页搜索和文章正文读取使用 MaiBot 主程序的统一联网服务（`ctx.web.search` / `ctx.web.fetch`）；需要这些功能时，在主程序「模型设置→功能分配→联网搜索」中配置并启用服务。费用与配额取决于宿主所选服务。

插件「联网」设置节提供：

- **启用联网**：联网工具、新闻阅读与主动探索的共同总开关；
- **允许麦麦使用联网搜索工具**：开启后 Planner/Replyer 可调用 `mai_life_web_search` 查询近期事实、未知知识和资料来源；工具不直接发送消息、不自动创建主动契机，查询前会清除 QQ 号、自动昵称和群名称；
- **失败重试次数**：宿主搜索失败时按次数短退避重试（默认 3 次），仍失败记录历史并返回明确说明；
- **记录搜索历史**：本地留痕每次逻辑搜索的查询词与结果摘要（可在 WebUI「记忆与牵挂→联网见闻与搜索」查看），可关闭。

新闻阅读与主动搜索默认各每天 1 次；失败或空结果也计入，避免持续请求。新闻默认从以下内置源交替选取近三天的条目，全部失败或没有近期条目时，回退到按人格规划的宿主搜索。模型不可用时仍可保存真实来源摘要；搜索失败保留旧缓存，不生成虚假见闻。正文经宿主 `web.fetch` 读取；只有订阅或搜索摘要时明确标注，不能声称已阅读全文。

| 配置值 | 新闻源 | 主要内容 |
| --- | --- | --- |
| `ithome` | [IT之家](https://www.ithome.com/rss/) | 科技与数码新闻 |
| `solidot` | [Solidot](https://www.solidot.org/index.rss) | 科技、科学与开源动态 |
| `sspai` | [少数派](https://sspai.com/feed) | 数码、效率工具与生活方式 |

在宿主插件配置中开启「联网→启用联网」和「启用新闻阅读」即可使用默认三源。手动配置对应如下（合并进已有 `[network]`，不要重复创建该节）：

```toml
[network]
enabled = true
news_enabled = true
news_sources = ["ithome", "solidot", "sspai"]
```

可以在 `news_sources` 中只保留想读的源；设为 `[]` 则只使用宿主新闻搜索。WebUI「记忆与牵挂→联网见闻与搜索」显示当前订阅源、来源链接和阅读内容。首次读取在允许的新闻时段执行，仍受每日次数限制。

### 小说阅读与学习

在插件安装目录的 `novels/` 放入你有权使用的 UTF-8 `.txt` 小说，即可按顺序分段阅读；`reading.directory` 可改为插件目录内的其他相对路径。阅读默认开启，每天最多 4 次，两次间隔至少 60 分钟；分段长度由 `reading.chunk_chars` 控制。没有小说、文件无效或阅读失败时跳过，不编造阅读经历。

阅读会持久化文件来源、已读位置、原文摘录与读后笔记，重启后继续；模型不可用时保存原文摘记，不生成虚构感想。阅读材料和笔记按私人内容处理，仅向主人提供上下文，不把原文和笔记放入公开分享。这里的“学习”指把实际读到的内容保存为后续对话可用的上下文记忆，不会训练模型或修改模型权重。

## 主要功能

### 生活与回复

- 全局维护一条任务时间线，不同用户看到同一份活动记录。
- 日程使用固定的新闻检索、主题探索、小说阅读与夜间待机时段，不调用模型生成生活框架或细化场景。
- 任务有真实结果才保存执行记录；待执行计划、失败请求和未读内容不计作已完成活动。
- 时间、天气、节假日、农历和日程作为独立背景，不强迫 Replyer 逐项播报。
- 配置私聊可注入关系角色、当前状态、未完话题、未回应摘要和生活记忆。
- 主人与朋友使用不同隐私边界；朋友不会获得主人专属称呼、私人日记和敏感上下文。

### 日常任务

08:00–10:00、12:00–14:00、18:00–23:30 用于新闻检索与主题探索，10:00–12:00、14:00–18:00 用于小说阅读，其余时段夜间待机。时段只表示允许执行的任务，实际执行还受开关、来源、每日额度与间隔限制；未执行时保留空记录。回复仍由工作时间和群聊概率控制。

### 消息体验

- 连发合并与撤回处理由 MaiBot 主程序接管，插件不重复提供消息防抖与撤回增强。
- 同轮回复防重：同一最终消息只允许一次独立 Replyer 回复（群聊轮次按“平台 + 群 QQ 号 + 发送者 QQ 号”隔离，可在「群聊设置→群聊轮次注册」关闭）；正常分段不受影响。

### 主动与社交

- 每个 QQ 用户拥有独立的关系温度、活跃时段、免打扰和每日主动额度。默认有限次，`daily_proactive_max` 是硬上限（`0` 禁止主动）；开启 `daily_proactive_unlimited` 后忽略这个日额度，用户的“允许主动”开关仍须开启。
- 不限次数只取消每日额度，实际发送仍遵守主动私聊总开关、用户主动开关、统一间隔、用户近期发言避让、工作时段和免打扰，不保证每天发送。
- “主动判断与发送间隔（分钟）”统一使用 `proactive.patrol_interval_minutes`，默认 `180`，范围 `1～1440`。每位用户分别计时；每轮最多选择一位符合约束且到期的用户交给 Planner，优先最久未判断者，多用户时可能略延后。判断时间持久保存在现有主动事件记录中，重启不会立即补一次判断。
- 没有生活契机或契机评分未达标时，也会给 Planner 自主考虑是否联系的机会；未达标的契机不作为参考，不得虚构生活事件。Planner 根据当前生活、当日实际主动次数、双方最近互动和上次主动是否未获回复决定是否开口，不因巡检或不限次数凑数，不催回复。
- Planner 可以沉默，沉默不消耗发送额度，但仍至少等待一个周期；实际发送后也至少等待同样的间隔再判断或发送。旧配置中的 `min_interval_minutes` 自动合并到 `patrol_interval_minutes`，两项都有时取较长值，保存后只保留统一项。缩短间隔或开启不限次数可能增加宿主模型调用。
- 群聊观察只保存匿名短摘要，不保存群聊原文。
- `/麦麦转述 群QQ号 内容` 只触发目标群 Planner，不构造 `@`，也不解析群名、昵称或别名。
- 群转私仅比较真实 QQ 号，并同时受离群时间、用户主动设置和隐私规则限制。

### 日记与记忆

- 日记只总结已有的实际执行记录与匿名互动数量；最近 7 天可补记有记录的日期，停机或没有实际活动的日期不补造经历。
- 重要日期继续作为定向提醒和主动话题的来源。
- 日记写作与小说阅读独立保留，日记和阅读笔记以 SQLite 明文保存，私人内容不向朋友提供。
- 小说创作、续写、灵感采集和绘画入口已移除；旧作品保留在数据库中，不再展示、注入或选作主动话题。旧配置中的相关字段被忽略，不会重新启用功能。
- 旧梦境数据保留在原数据库中供兼容，不再生成、注入或选作主动话题。

## 运行影响

| 项目 | 影响 |
| --- | --- |
| 响应延迟 | 消息路径不联网校时、不调用判醒模型；群聊仅做一次本地概率判断。首次启动校时最多等待约 12 秒。 |
| Token | 固定日程与执行记录不调用模型生成；日记、阅读批注、连续话题、新闻整理、见闻关联和主动判断会增加模型调用或 Prompt 长度。实际用量取决于模型、用户数量、开关与频率，可在 WebUI 查看统计。 |
| 联网与费用 | 内置 RSS 直接读取公开订阅，搜索与正文读取走主程序统一服务；新闻/主动搜索默认各每天 1 次，联网工具不设上限。模型及搜索服务费用以所配服务的计费为准。 |
| 存储与隐私 | SQLite 保存生活、QQ 关系资料、日记、阅读笔记、重要日期、搜索历史和调用统计，不保存图片二进制。私人文本为明文，需限制数据目录权限；搜索历史可关闭，群观察只保留匿名短摘要。 |

## 指令

| 指令 | 用途 |
| --- | --- |
| `/麦麦`、`/麦麦帮助` | 返回纯文本指令菜单；未识别指令也会落进同一菜单 |
| `/麦麦状态` | 查看生活、消息管线、联网和后台任务状态 |
| `/麦麦配置` | 查看配置摘要 |
| `/麦麦添加日期 YYYY-MM-DD 名称` | 添加当前用户的重要日期，需要启用用户档案 |
| `/麦麦删除日期 编号`、`/麦麦确认日期 编号 [YYYY-MM-DD]` | 删除重要日期或确认日期候选，需要启用用户档案 |
| `/麦麦转述 群QQ号 内容` | 主人或管理员发起简单群转述 |
| `/麦麦重生日程`、`/麦麦休息测试` | 主人或管理员重建日程；查看校准时间、来源与回复工作时段 |

所有指令仅允许在私聊中使用。启用用户档案的 QQ 可使用个人功能；管理员 QQ 可直接使用菜单和诊断类功能。管理员、主人和用户身份始终只按 QQ 号判断。

当前有以上 10 条公开指令；保留对应的 `/mai_*` 英文兼容入口。日程、关系、日记、日期、联网见闻、阅读笔记和用量统计通过 MaiBot WebUI 的三个页面查看；已移除的旧指令会显示菜单。
